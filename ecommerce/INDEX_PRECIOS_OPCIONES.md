## 🚀 Inicio Rápido en 3 Pasos

### Paso 1: Configurar en Admin (5 min)
```
Admin → Productos → Selecciona producto → Atributos → 
Opción → Asigna "Costo adicional" → Guarda
```
Ver: [CAMBIOS_PRECIOS_OPCIONES.md](#cambios)

### Paso 2: Ver en Tienda (2 min)
```
Tienda → Selecciona producto → Ver opciones con badges +$50.00
```
Ver: [CAMBIOS_PRECIOS_OPCIONES.md](#cambios)

### Paso 3: Verificar en Carrito (3 min)
```
Carrito → Verifica que precio se calcula correctamente
```
Ver: [VERIFICACION_PRECIOS_OPCIONES.md](#verificacionpreciosopciones)
